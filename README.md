# GoGoPlus Landing Page

This project is a Next.js 15 App Router application styled with Tailwind CSS 4.

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```

The dev server will boot on [http://localhost:3000](http://localhost:3000) by default. Any edits you make under the `app/` directory will hot-reload automatically.

## Additional scripts

- `npm run build` – Create an optimized production build.
- `npm run start` – Serve the production build locally (after running `npm run build`).
- `npm run lint` – Run Next.js lint checks.
